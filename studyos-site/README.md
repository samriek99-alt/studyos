# StudyOS

A school and UCAT planning website preview.

## Hosting
Upload `index.html` to the root of your GitHub repository. In Settings → Pages, choose Deploy from a branch, `main`, `/ (root)`, and Save.

## Important
This preview stores data in the current browser using localStorage. **It does not sync across devices.** Do not enter sensitive information until Supabase authentication and Row Level Security are configured in a future version. Never put a Supabase service-role/secret key or database password in browser code.
